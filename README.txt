DAILY TASK PLANNER

Files:
- index.html: page structure
- style.css: design and layout
- script.js: task features

How to run:
1. Extract this ZIP file.
2. Open the daily_task_planner folder.
3. Double-click index.html. It opens in your browser.

Features: add tasks, set due dates and priorities, mark tasks complete, edit/delete tasks, filter tasks, and save tasks in this browser using localStorage.
Note: tasks are saved in the browser on this device, not in an online database.
